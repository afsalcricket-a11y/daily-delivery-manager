
# 🚚 Daily Delivery Manager

**Daily Delivery Manager** is an operational tracking tool built for recurring local delivery businesses (such as milk, tiffin, water cans, or newspaper vendors) to manage daily drop-offs, customer quantities, and monthly billing summaries.

🔗 **Live Demo:** [https://afsalcricket-a11y.github.io/daily-delivery-manager/](https://afsalcricket-a11y.github.io/daily-delivery-manager/)

---

## ✨ Key Features

- **Customer & Subscription Setup:** Manage recurring customer profiles along with default item quantities and unit rates.
- **Daily Delivery Checklist:** Mark deliveries as *Delivered*, *Skipped*, or *Adjusted Quantity* with a single tap each day.
- **Automated Monthly Billing:** Aggregates daily delivery logs into accurate end-of-month totals per customer.
- **Daily Dispatch Summary:** View total units required for the day before starting the delivery route.
- **Responsive Design:** Optimized for quick field updates on smartphones and reporting on desktops.
